# IntelliLearn AI

## Personalized AI-Powered Learning Assistant

IntelliLearn AI is an AI educational platform that helps students:
- learn topics,
- generate quizzes,
- summarize notes,
- analyze learning sentiment,
- and create study roadmaps.

## Features

- AI Tutor
- Quiz Generator
- Notes Generator
- Sentiment Analysis
- Study Roadmap Generator
- Learning Dashboard

## Technologies

- Streamlit
- Groq API
- Plotly
- NLP
- Python

## Deployment

Deployed using Streamlit Community Cloud.
